这几个月关注到各 AI 厂商的智能体产品演进大趋势是：不再做一堆分散独立产品，而是大量合并收拢。大致分「编程 IDE 」和「通用办公工作台」两套产品线。其中更有甚者 OpenAI 想整出编程、办公大一统的 GPT‑Work…

（PS：这谁再说只有国内好做一堆功能的软件 😏）

| 厂商 | 编程 | 通用智能体 |
| --- | --- | --- |
| 阿里系 | Qoder | 千问办公 |
| 腾讯系 | CodeBuddy | WorkBuddy |
| 字节系 | TreaCode（原 Trea） | TreaWork |
| DeepSeek | DeepSeek‑Harness（开源框架，非成品） |   |
| Kimi | KimiCode | KimiWork |
| 智谱 | zcode | AutoGLM、智谱清言… |
| OpenAI | Codex | GPT‑Work |
| Anthropic | Claude‑Code (CLI + 简易 GUI) | 无 |


关注到 DeepSeek 推出开源 DSH（DeepSeek‑Harness）后，各种功能的插件、各自技术选型的客户端一夜之间井喷。各家本来正从卷模型到卷 AI 智能体产品，现在好，开始卷 Agent 执行层（文件读写、终端、Agent 循环等）了 🫣。

后续打算整理下各大模型厂商及其 Agent 智能体产品的衍进，不过发展变化实在太快了 🥲，今日总结明天可能就过时了！
